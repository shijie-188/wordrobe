自动备份

每天首次打开时自动存一份，最多保留 7 份。恢复前会把当前数据也存一份，可以再退回。

云同步（GitHub）

手机在外面也能用：应用放到 GitHub Pages，数据同步到你自己的私有仓库。 浏览器能直连 GitHub，不用再买服务器。

GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens 新建：Repository access 选「Only select repositories」勾这一个仓库； Permissions 里把 Contents 设成 Read and write。 令牌只存在这台设备的浏览器里，不会写进导出备份。

同步什么：衣服资料写进仓库里的 data.json，每张照片写进 photos/ 下一个文件。 第一次上传要把已有照片都传上去（几十 MB，会慢一次），之后只传新增的。
不会偷偷传：只有你点「上传到云端」才会往外写；打开页面只在本机一件衣服都没有时自动拉一次（新手机第一次打开就有数据）。

AI 设置

认衣服（云端）：填了 Key 才能用，认出品类，顺手起个名称、写一句备注。 用的是智谱的免费多模态模型 GLM-4V-Flash。

到 open.bigmodel.cn 注册 → 打开「API Keys」新建一个。免费模型不用绑卡。
⚠️ Key 只存在「这台设备」的浏览器里（和云同步、导出备份都无关）—— 换手机 / 换电脑要重新粘贴一次。认衣服和配一套是调智谱的服务器， 本机不需要任何模型文件。

如果提示「模型不存在 / 无权限」，换回 glm-4v-flash 就行（免费模型之间不产生费用）。

「AI 配一套」用它：只发衣服的名字 / 品类 / 颜色 / 备注，不发照片。 默认 glm-4-flash（免费、快）。glm-4.7-flash 会想很久容易卡住，不建议用。

品类会直接用 AI 的结果；你自己动过品类的话，它只会变成一条可点的提示。 名称、备注、颜色只在你还没自己填过的时候才写进去。

隐私：用 AI 就等于把照片上传给智谱。只有你点「AI 识别」的那一刻才会传，不点就不联网。 Key 只存在这台设备的浏览器里，不会写进导出备份、也不会同步出去。

衣服专用模型把每个像素分成 18 类（上装 / 裤子 / 裙子 / 鞋 / 包 / 围巾…），只留衣服那几类， 所以出来的是衣服本身的形状，而不是「整个人」。它没搞定时会自动退回通用模型，不让你白点一次。 两个模型的下载源都是国内可达的镜像，下完缓存在浏览器里。

这个抠图是在你自己的设备上跑的，照片不外传，代价是首次要下一个模型。 不传任何文件也能用：手机 / 电脑会在第一次点抠图时自己从网上下载模型（慢一次，之后缓存）。 想在手机上更快更稳（尤其放在 GitHub Pages 上用），把模型文件传到你的公开仓库。 目录必须这样放（transformers.js 要求这个结构）：
　clothes-model/Xenova/segformer_b2_clothes/ 下面放这 4 个文件： config.json、preprocessor_config.json、quantize_config.json、 model_quantized.onnx（共约 27.5MB）。
放对了会在「照片自检」里看到「模型：本机 clothes-model ✓」； 只把文件平铺在 clothes-model/ 下会提示「摆放不对」，那它就还是走网络。 注意：本地目录只有在 http(s) 打开时才有效，双击 file:// 打开的页面读不了本地文件。
